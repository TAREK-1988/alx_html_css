# Headphones Landing Page

This project is part of the **ALX Front-End** curriculum.  
The goal is to **implement a pixel-perfect, responsive landing page** from a Figma design using only **HTML and CSS** (and a small amount of vanilla JavaScript in the final task for the hamburger menu).

## Project Overview

- Design name: **Headphones Landing Page**
- Designer: **Nicolas Philippot (UI/UX)**
- Repository: `alx_html_css`
- Directory: `headphones`

The objective is to reproduce the Figma design as closely as possible:
- Correct layout and alignment
- Correct typography and spacing
- Correct colors and hover states
- A fully responsive layout that switches to mobile view at `480px` or below

> No external CSS frameworks (like Bootstrap, Tailwind, etc.) are allowed.

## Figma Design

You can find the final screens in the Figma file provided in the project instructions on the intranet.

If the fonts are missing on your computer, you can download and install:

- **Source Sans Pro**
- **Spin Cycle OT**

Some values in the design are floats (e.g., `13.333px`). It is acceptable to round them to sensible values.

## Interactions & Requirements

- **Max content width:** `1000px`, centered on the page
- **Mobile breakpoint:** at `480px` or less
  - The layout must switch to the mobile version
- **Links hover/active color:** `#FF6565`
- **Button hover/active:** `opacity: 0.9`
- **Accessibility:** semantic HTML, labels for form inputs, alt attributes on images, etc.
- **No JavaScript** for most tasks  
  - JavaScript is only allowed and required in **Task 8** for the hamburger menu.
