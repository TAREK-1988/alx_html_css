# CSS Advanced – SmileSchool Homepage

This project is part of the **ALX Front-End** curriculum and follows the **HTML, advanced** project.

The goal of this project is to build the **SmileSchool** homepage using only **HTML and CSS**, based on the Figma design.

## Objectives

By the end of this project, I should be able to:

- Explain what CSS is and how it works with HTML
- Add style to elements using selectors, classes and IDs
- Compute CSS specificity values
- Work with the CSS box model (margin, padding, border, content)
- Understand, at a high level, how the browser loads and renders a webpage

## Project files

- `index.html` – HTML structure of the SmileSchool homepage  
- `styles.css` – Main stylesheet of the page (header, banner, quotes, videos list, membership, FAQ, footer)

> `styles.css` will be created and completed in the next tasks.

## Requirements

- No external frameworks (no Bootstrap, React, Vue, etc.)
- Only HTML and CSS (and very basic JavaScript if needed)
- Code must be valid according to the W3C validator
- All files must end with a new line

## Design

The final design is available on Figma:

- Page in Figma (Homepage)
- `.fig` file
- Project images provided by ALX

Make sure to **duplicate the Figma file to your drafts** in order to inspect all paddings, font sizes, colors and other design details.

## How to run

Simply open `index.html` in your browser.
